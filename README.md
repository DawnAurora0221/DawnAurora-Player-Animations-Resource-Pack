## 🧪 Under the Hood · 技术内幕

<details>
<summary><b>🧬 How Are CEM Expressions Written? · CEM 表达式怎么写的？（Click to expand · 点击展开）</b></summary>

<br>

DawnAurora is fully based on the **OptiFine / EMF CEM (Custom Entity Models) expression system**, with zero custom code mods. The core idea:  
DawnAurora 完全基于 **OptiFine / EMF 的 CEM（Custom Entity Models）表达式系统**，不依赖任何自定义代码模组。核心思路：

```text
Animation Value = Base Pose + Physics Offset (variable) × Damping Coefficient
动画值 = 基础姿态 + 物理偏移(变量) × 阻尼系数
```

Typical techniques · 几个典型手法：

| Technique · 手法 | Description · 说明 |
|---|---|
| `sin(age / N)` | Generates a periodic breathing wave; larger `N` = flatter. · 生成周期性的呼吸波，`N` 越大越平缓。 |
| `clamp(x, min, max)` | **The lifesaver function.** Any potentially diverging physical value must be clamped, or the model flies into outer space. · **保命函数**。任何可能发散的物理量都要夹住，否则模型会飞到外太空。 |
| `if(condition, A, B)` | State machine branching: ground / gliding, walking / idle, damaged / normal. · 状态机分支：地面 / 滑翔、行走 / 静止、受伤 / 正常。 |
| `limb_speed` | Gait frequency driver — the core input for "walking with inertia." · 步频驱动，是"走路有惯性"的核心输入。 |
| `fall` | Fall speed, driving landing compression and weightless lift. · 坠落速度，驱动落地压缩与失重上扬。 |
| `var.*` | Custom intermediate variables, caching last-frame displacement deltas (e.g. `body_ty_diff`). · 自定义中间变量，用于缓存上一次的位移差（如 `body_ty_diff`）。 |
| `time` / `age` | Global time, driving periodic breathing and sway. · 全局时间，驱动周期性呼吸与摆动。 |
| `math.sin()` / `math.cos()` | Trigonometry — the foundation of physical sway. · 三角函数，物理摇摆的基础。 |
| `math.atan2()` | Angle calculation for orientation alignment. · 角度计算，用于朝向对齐。 |

> ⚠️ **Blood-earned lesson: `var.*` is infinitely amplified under tiny displacements — it MUST be clamped.**  
> ⚠️ **血的教训：`var.*` 在微小位移下会被无限放大，必须 `clamp`。**

> 💬 *"`clamp` is the CEM developer's seatbelt. You don't have to use it, but don't blame the model for flying off-screen."*  
> 💬 *"`clamp` 是 CEM 开发者的安全带。你可以不用，但别怪模型飞出屏幕。"*

## 🩺 Ultimate FAQ · 终极排障与急救大百科

<details>
<summary><b>❓ Q1: Why is Steve a vegetable / doing nothing after installing? · 为什么装了之后史蒂夫变成植物人 / 没有动作？🤖</b></summary>

👉 **A:** Check dependencies first. You must install **EMF + ETF** and enable DawnAurora in the resource pack list. If using OptiFine, you must manually enable **Video Settings → Quality → Custom Entity Models**, otherwise animations won't take effect. During Alpha, EMF + ETF is recommended for higher stability. ✅  
👉 **A：** 先检查前置。必须安装 **EMF + ETF**，并在资源包列表中启用 DawnAurora。若使用 OptiFine，必须在 **视频设置 → 质量 → 自定义实体模型** 中手动开启，否则动作不会生效。Alpha 阶段建议使用 EMF + ETF，稳定性更高。✅

</details>

<details>
<summary><b>❓ Q2: The animations work, but the cape still slaps my face / flies around? · 为什么动作生效了，但披风还是糊脸 / 乱飞？🌪️</b></summary>

👉 **A:** First confirm you are not also running other resource packs or mods that modify the player model or cape animation. DawnAurora already introduces multi-axis damping and `clamp` limits; normally the cape folds inward when walking backward. If it's still abnormal, attach the game version, dependency versions, screenshots, or a short video so we can locate it. 📸  
👉 **A：** 先确认没有同时安装其他修改玩家模型或披风动画的资源包 / 模组。DawnAurora 已引入多轴阻尼与 `clamp` 限位，正常情况下倒退时披风会向内折叠。如果仍异常，请附游戏版本、前置版本、截图或短视频，方便定位。📸

</details>

<details>
<summary><b>❓ Q3: The torch sways too much / not at all — what do I do? · 火把动作太晃 / 完全不晃怎么办？💡</b></summary>

👉 **A:** The torch includes breathing micro-motion, pendulum inertia, and gravity feedback. Idle, walking, sprinting, falling, and landing all feel different. If the amplitude doesn't suit you, record the specific scenario (first/third person, idle/moving/landing); future versions will tune parameters based on feedback. ⚙️  
👉 **A：** 火把包含呼吸微动、钟摆惯性和重力反馈。待机、走路、疾跑、坠落、落地的手感不同。如果觉得幅度不合适，请记录具体场景（第一人称 / 第三人称、待机 / 移动 / 落地），后续版本会按反馈调参。⚙️

</details>

<details>
<summary><b>❓ Q4: Why doesn't the blink system show up? · 眨眼系统为什么不显示？😉</b></summary>

👉 **A:** Blinking depends on the head CEM skeleton animation layer and requires EMF/ETF or OptiFine's Custom Entity Models to be active. If you use a custom skin, confirm the skin doesn't overwrite or replace the head animation layer. During Alpha, if you see eyelid flicker or Z-fighting, please attach a screenshot. 👁️  
👉 **A：** 眨眼依赖头部 CEM 骨骼动画层，需要 EMF/ETF 或 OptiFine 的自定义实体模型生效。若使用自定义皮肤，确认皮肤没有覆盖或替换头部动画层。Alpha 阶段如出现眼皮闪烁、Z-fighting，请附截图。👁️

</details>

<details>
<summary><b>❓ Q5: Does the elytra still shake on the ground? Is gliding normal? · 鞘翅在地面还会抖吗？滑翔时正常吗？🦅</b></summary>

👉 **A:** On the ground the elytra uses rigid attachment and should theoretically not shake or float; aerodynamic extension and swept-back wingtips only activate while gliding. If it still shakes on the ground, first check for conflicts with other elytra / player model resource packs. 🛑  
👉 **A：** 地面状态下鞘翅采用刚性贴合，理论上不抖不飘；滑翔时才会启用空气动力延展和后掠翼尖。若地面仍抖动，优先排查是否与其他鞘翅 / 玩家模型资源包冲突。🛑

</details>
